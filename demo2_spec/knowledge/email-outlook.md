# Email and Outlook

Document-ID: DOC-EMAIL-001

## Outlook will not open

Close Outlook fully, including the icon in the system tray, then reopen it. If it still stalls on a profile, start Outlook in safe mode and disable the last add-in you installed. Mailbox storage over ninety percent will also stop send. Delete large Sent items or ask for an archive.

## Missing mail

Check the Focused tab, the Junk folder, and any rule that moves mail from executives. Northstar does not recover a message that was deleted from Deleted Items more than fourteen days ago. A widespread delay is an email service incident; check service status before you rebuild the profile.

## Shared mailbox

A shared mailbox is granted by the mailbox owner. The help desk cannot add you because a client presentation is soon. Request access from the owner, then restart Outlook.

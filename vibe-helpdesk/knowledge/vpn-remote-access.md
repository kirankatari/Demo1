# Northstar Connect VPN

## When the VPN keeps disconnecting

Employees who are working remotely may see Northstar Connect disconnecting, especially in the 30 minutes before a client presentation. Check service status before any reinstall. If the VPN status is degraded, a client reinstall will not fix the gateway.

Short path when a meeting is inside 30 minutes:

1. Do not start a full client reinstall.
2. Open Northstar Connect and choose the profile named Backup Gateway.
3. If Backup Gateway also drops, join the presentation from a phone hotspot.
4. Leave split tunneling off so the meeting stays on the tunnel.
5. After the meeting, write down the local time of each drop and the network name.

## Checks that are safe before a meeting

A laptop clock that is off by more than five minutes causes the gateway to reject the session. Forget and rejoin home Wi-Fi only when you are not already in the meeting. Quit every other VPN client. Only Northstar Connect should be running.

## Questions that change the next step

Ask which operating system Northstar Connect is running on, and whether the disconnect happens only on the current Wi-Fi. Do not delay the Backup Gateway or hotspot workaround when a client presentation is imminent.

## Escalate

Open a network ticket at priority P1 when a customer-facing presentation is within two hours and the VPN is still disconnecting after Backup Gateway or a hotspot was tried. Include the gateway profile, the operating system, and the times of the drops. The ticket is not created until the employee confirms it.

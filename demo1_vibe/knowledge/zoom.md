# Meetings and Zoom

Document-ID: DOC-ZOOM-001

## Join a client meeting

Northstar meetings run on the company Zoom tenant. Join with the desktop client if it is already signed in. If the client is stuck, use the browser join link rather than reinstalling during the last thirty minutes before a presentation. Mute on entry. Do not record a client meeting unless the invite says recording is allowed.

## Audio problems

Select the headset in Zoom audio settings, then leave and rejoin. A VPN disconnect can freeze Zoom media even when the meeting window is still open. Fix the gateway using the VPN troubleshooting document, or switch the laptop to a phone hotspot for the length of the presentation.

## Account not licensed

A missing Zoom license is a software request. It is not an urgent outage unless the meeting is within the hour and no browser join is possible.

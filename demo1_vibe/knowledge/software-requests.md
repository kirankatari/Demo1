# Software requests

Document-ID: DOC-SW-001

## Catalog installs

Northstar laptops install approved software from the company portal. That list includes the browser, Zoom, GlobalProtect, and the office suite. Other tools need a software request with a business reason. The help desk drafts the request and you confirm it before it is submitted.

## Not an outage

Wanting a new application is not a VPN incident and not an urgent ticket, even on a presentation day, unless the missing application is the only way to run that presentation and the meeting is inside one hour. In that case the priority follows the ticket priority document.

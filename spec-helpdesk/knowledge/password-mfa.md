# Passwords and MFA

## Reset a forgotten password

Employees who forgot a password use the Northstar Account Portal at https://accounts.northstar.example and choose Reset password. The portal sends a one-time code to the recovery address on file. The service desk cannot read or set a password.

If the recovery address is old, file an access ticket and bring an employee ID. Priority is P3 unless the lockout blocks a customer meeting already on the calendar, in which case use P2.

## MFA codes

Authenticator codes refresh every 30 seconds. If an MFA code is rejected, wait for the next code. Do not enter the old code twice. SMS backup is allowed only when the authenticator device is unavailable.

## Locked accounts

Five bad passwords lock the account for 15 minutes. Do not open a ticket during that wait unless the lockout continues after the 15 minutes. Never paste a password or MFA code into the help desk chat.
